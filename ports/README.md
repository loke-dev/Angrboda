# Angrboða ports

All files in this directory are generated by `npm run build`. Copy or import the
file for your tool; do not edit generated files directly.

## Automatic installation

The npm package and release bundle include a dependency-free Node installer for
ports whose theme files have stable user-level locations:

```sh
npx angrboda list
npx angrboda ghostty --dry-run
npx angrboda ghostty
```

It supports Alacritty, Codex, Gemini CLI, Ghostty, Helix, Kitty, OpenCode,
WezTerm, and Zed. Pass `--target <directory>` to use a custom config location.
The installer
does not edit activation settings; it prints the exact final step for the
selected tool. It refuses differing existing files by default. `--force`
creates a timestamped backup before replacing them, while `--dry-run` identifies
the files that would require `--force`.

If you downloaded the release ZIP, replace `npx angrboda` with
`node install.mjs` in these commands.

## Zed

Copy `zed/angrboda.json` into `~/.config/zed/themes/` on macOS or Linux, or
`%USERPROFILE%\AppData\Roaming\Zed\themes\` on Windows. Restart Zed, then choose
**Angrboða Dark** or **Angrboða Light** from the theme selector.

## Sublime Text

Open **Preferences → Browse Packages**, enter the `User` directory, and copy
both files from `sublime-text/` into it. Choose the desired Angrboða scheme from
**Preferences → Select Color Scheme**.

## Helix

Copy both files from `helix/` into `~/.config/helix/themes/` or
`%AppData%\helix\themes\` on Windows, then add this to `config.toml`:

```toml
theme = "angrboda-dark"
```

## Ghostty

Copy both files from `ghostty/` into `~/.config/ghostty/themes/`, then add:

```ini
theme = dark:Angrboda Dark,light:Angrboda Light
```

## Kitty

Copy the desired file from `kitty/` into your Kitty config directory and add
this to `kitty.conf`:

```ini
include angrboda-dark.conf
```

## Alacritty

Copy the desired TOML file from `alacritty/` and import it from
`alacritty.toml`:

```toml
import = ["~/.config/alacritty/angrboda-dark.toml"]
```

## Warp

Copy the files from `warp/` into Warp's custom theme directory, restart Warp if
needed, and choose Angrboða in **Settings → Appearance**.

## WezTerm

Place `wezterm/angrboda.lua` next to `wezterm.lua`, then merge and select a
scheme:

```lua
local angrboda = require("angrboda")
config.color_schemes = angrboda
config.color_scheme = "Angrboda Dark"
```

## Windows Terminal

Merge the two entries in `windows-terminal/angrboda.json` into the `schemes`
array in Windows Terminal settings, then set a profile's `colorScheme` to
`Angrboda Dark` or `Angrboda Light`.

## iTerm2

Open **Settings → Profiles → Colors → Color Presets → Import**, import both
files from `iterm2/`, and choose the appropriate preset. iTerm2 can assign the
two presets to separate light and dark appearances.

## OpenCode

Copy `opencode/angrboda.json` to
`~/.config/opencode/themes/angrboda.json`, then run `/theme` and choose
`angrboda`. The single file adapts to dark and light appearances.

## Gemini CLI

Install both native custom-theme files:

```sh
npx angrboda gemini
```

The installer prints the full path to each theme. Set `ui.theme` in
`~/.gemini/settings.json` to the dark or light JSON path, or select the theme
with `/theme` after registering it in `ui.customThemes`.

## Codex

Copy both `.tmTheme` files to `~/.codex/themes/`:

```sh
mkdir -p ~/.codex/themes
cp ports/codex/angrboda-dark.tmTheme ports/codex/angrboda-light.tmTheme ~/.codex/themes/
```

Open Codex CLI and run `/theme` to switch between `angrboda-dark` and
`angrboda-light`. For the Codex desktop app, open Settings → Appearance and
use the `codex-theme-v1:` payload from either
`ports/codex/angrboda-app-dark.txt` or `ports/codex/angrboda-app-light.txt`.

## Chrome and DevTools

Chrome DevTools does not expose a third-party full-theme API. Angrboða uses the
supported dynamic-theme path instead:

1. Open `chrome://extensions`, enable **Developer mode**, and choose
   **Load unpacked**.
2. Select the `chrome/` directory.
3. In DevTools, open **Settings → Preferences → Appearance** and enable
   **Match Chrome color scheme**.

Chrome's frame, toolbar, tabs, new-tab page, and DevTools appearance will then
share the Angrboða atmosphere.

## Base16

The `base16/` directory contains dark and light schemes following the current
Tinted Theming Base16 YAML format. Use either file with Tinty, Flavours,
base16-shell, or any compatible template builder to generate themes for dozens
of additional applications.

## AI coding tools

Gemini CLI has native dark and light custom themes, and OpenCode has a native
adaptive port. Codex is supported through `.tmTheme` files for CLI and
codex-theme-v1 payloads for the app. Cursor and Windsurf can use the VSIX,
Zed's assistant uses the Zed theme, and terminal-native tools such as Claude
Code inherit Angrboða from the surrounding terminal. This avoids fragile or
unsupported UI overrides while keeping the full session visually coherent.
